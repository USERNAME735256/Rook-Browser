# Rook-Browser
Rook Browser is a school proxy that has many features. For starters, it uses Wisp and LIBCURL.js so I can stay in a SINGLE file; this makes it unblockable. It uses libcurl to strip off the X-Frame header, meaning its untrackable and can browse the millions of websites the WWW (World Wide Web) has. 

Go to index.html and download the file, open it, and boom, you have an entire unblocked browser
